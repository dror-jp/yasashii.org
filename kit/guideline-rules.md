# 入管庁ガイドライン抽出ルール（機械抽出 2026-07-13）

出典: 在留支援のためのやさしい日本語ガイドライン 本編（moj.go.jp 930006072.pdf・全17頁読了）
+ 別冊（930006077.pdf・全18頁読了 = **文例集ではなく行政・生活用語134語の語彙集**だった点に注意）

## 設計上の大前提（本編p5）
「このガイドラインではあえて厳密な基準は示していません」— 数値基準はほぼ皆無。
→ **チェッカーは合否判定ではなく「要確認箇所のハイライト」型**が原典の思想に忠実。
→ 文字数上限などの閾値（一文40〜50字目安等）は当プロジェクトの自主基準として明示する。

## 書き換え例（本編第4章より・行政手続き関連の要点）

- 転入: 「在留カードが交付された方（後日交付となった方を含む。）は、住所を定めた日から14日以内に…転入の届出をする必要があります」→「住所が決まってから14日以内に、住所がある町の役所に「転入届」を出します。役所には、パスポートか「在留カード」を持っていきます。」
- 受身回避: 「住民税は、市町村で課税されます」→「住民税は、市町村へお金を払います」
- 婚姻: 「婚姻をするときは、役所に届出をし、届出が受理されると、婚姻が成立します」→「結婚するときは、役所に「婚姻届」を出します。役所が「婚姻届」を受理すると、結婚が成立します。」

## 別冊語彙集の代表例（用語辞書のシード）

- 転入届: 別のまちから引っ越しをしたときに、新しい住所の役所に出す紙。引っ越しをして日本に住み始めたときにも出します。
- 国民健康保険: 会社の健康保険などに入っていない人が、自分で入る医療保険。
- 固定資産税: 土地や家を持っている人が払う税金。
- 緊急地震速報: 強い地震が来る少し前に、テレビやスマートフォンに出るお知らせ。
- ハザードマップ: 災害が起きたときに、危ない場所や逃げる場所が書いてある地図。
（→ 全134語を Phase 1 で terms辞書化し、プロンプトのRAGソース+glossaryデータにする）

## 実装への反映方針

1. チェッカー: 合否でなく警告型。固定パターン(a群①)+形態素解析(a群②: 受身・使役・敬語・述語数)。
2. プロンプト: 本編のSTEP1(情報整理)→STEP2(文・言葉・表記)→STEP3(確認)の**多段構造をプロンプト自体に反映**。
3. 人間検証(#29)はガイドラインが必須と規定 — Tier設計(verified=人間検証済みのみ)の公的根拠として明示できる。
4. 参考ツール(本編第3章): やんしす/やさにちチェッカー/リーディングチュウ太。
