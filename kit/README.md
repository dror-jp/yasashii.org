# やさしい日本語 変換キット

yasashii.org の文書を作るために使っている道具一式です。**自治体・支援団体・開発者が自由に使えます。**

出入国在留管理庁×文化庁「在留支援のためのやさしい日本語ガイドライン」に準拠しています。

## 中身

| ファイル | 何か |
|---|---|
| [prompt-v1.md](prompt-v1.md) | LLM（Claude等）用の変換プロンプト。ガイドラインのSTEP構造（情報の取捨選択→語彙・文法→表記）に沿って行政文書をやさしい日本語に書き換えます |
| [guideline-rules.md](guideline-rules.md) | ガイドライン本編PDFから抽出した29ルール。機械判定できるもの／LLMが判定するもの／人間にしか判定できないもの、の区分つき |
| [checker/](checker/) | 形態素解析（kuromoji）による機械チェッカー。文の長さ・漢語率・受身・二重否定などを検出します |

## チェッカーの使い方

```bash
cd checker
npm ci
node checker.mjs your-text.txt
```

出力はJSONです（平均文長・漢語率・jReadability近似値・警告リスト）。

**重要**: このチェッカーは合否判定ではなく「要確認箇所の提示」です。ガイドライン自体が意図的に数値基準を示していません（読み手に合わせて判断するため）。**人間の確認（STEP3）はガイドラインが必須と定める工程であり、機械チェックでは代替できません。**

既知の制約: 補助動詞（〜ています、〜てください）を述語として過剰カウントすることがあります。

## 変換の流れ（yasashii.orgでの実運用）

1. **国の一次情報を検証**する（省庁ページ・e-Gov法令。URLと確認日を記録）
2. 一次情報に基づいて **ゼロから書く**（自治体文書の書き換えはしない — 著作権の構造的回避）
3. prompt-v1.md で **変換・執筆**
4. checker で **機械チェック** → 実質的な警告を修正
5. **人間が確認** → 確認できた文書だけ「✓ 人が 確認しました」と表示
